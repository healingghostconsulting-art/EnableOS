# CHCG Three Agent Trainings — Creative Direction

## Purpose

This brief defines how the first three CHCG agent trainings should feel after the next content pass. The objective is to make them more complete, more human-crafted, and more memorable inside the product without changing the core learning goals already established in the content.

## Shared content standard

The trainings should sound like a strong CHCG coach is guiding the learner through real interaction moments, not like a generic slide deck has been pasted into a course player. The writing should remain concise, but each page should carry a specific instructional job.

Across all three modules, slide copy should become more visual and more decisive. Narration should do more of the explanatory work, while on-screen text should emphasize the moment, the pattern, the contrast, or the coaching takeaway.

| Content layer | Standard for the next pass |
| --- | --- |
| Hero copy | Shorter, more human, more outcome-focused |
| Core slides | Each slide must have a distinct purpose, not just another variation of the same explanation pattern |
| Practice slides | More grounded in realistic call moments and learner decisions |
| Supporting statements | Include stronger coach-like lines that feel quotable and reusable |
| Narration notes | Add speaker guidance that interprets the lesson and explains why the behavior matters |
| Visual framing | Support the lesson with more intentional module-specific moments, contrasts, and performance cues |

## Module 1 — Active Listening

This module should feel like **reading the moment before solving the problem**. The strongest version of the training should help the learner notice emotional signal, identify the ownership gap, and respond with a calm, structured opening.

The module should lean into three ideas. First, the learner must recognize that listening is not passive politeness; it is visible control. Second, the learner should hear stronger language models that sound natural, not scripted. Third, the lesson should make weak openings easier to diagnose.

### Recommended page jobs

| Page type | Direction |
| --- | --- |
| Hero | Frame listening as the move that slows the interaction down just enough to regain control |
| Core slide 1 | Show what the customer is really hearing in the first 30 seconds |
| Core slide 2 | Break the listening model into observable moves |
| Core slide 3 | Contrast weak versus strong openings |
| Practice | Let the learner decode the emotional signal before selecting a response |
| Apply | Make the learner prove they can choose acknowledgment plus ownership plus next step |
| Reflection | Push the learner toward one exact phrase they will test on the next call |

### Voice direction

The tone should be steady and controlled. It should sound like a coach helping someone sharpen their opening, not praising them for being nice. The best supporting lines here are short and precise, such as the idea that **the customer relaxes when they hear that someone actually has the conversation**.

## Module 2 — Confident Reassurance Without Overpromising

This module should feel like **precision language under uncertainty**. It should teach the learner that confidence is not optimism; confidence is being specific about ownership, process, and next step without pretending the outcome is already known.

The current structure is strong, but the next pass should make the wording more vivid and more memorable. The lesson should include sharper rewrites, clearer good-versus-risky language contrasts, and stronger coachable phrases that a learner could actually borrow in the next monitored interaction.

### Recommended page jobs

| Page type | Direction |
| --- | --- |
| Hero | Frame reassurance as a trust decision, not a tone choice |
| Core slide 1 | Show how strong reassurance sounds specific rather than vague |
| Core slide 2 | Contrast safe confidence with promise debt using side-by-side language |
| Core slide 3 | Show how reassurance changes when another team or delay is involved |
| Practice | Let the learner identify hidden promise risk in realistic phrasing |
| Apply | Require the learner to choose trust-protecting language under pressure |
| Reflection | Push the learner to retire one risky phrase and replace it with a stronger default |

### Voice direction

This module should sound composed, exact, and quietly confident. The strongest narration will explain not only what to say, but why certain phrasing sounds safer and stronger at the same time. The best supporting lines here are the ones that separate **certainty about effort** from **certainty about outcome**.

## Module 3 — De-escalation and Professional Recovery

This module should feel like **recovering the interaction in real time**. The learner should feel the emotional temperature shift as they move through the lesson. Rather than presenting de-escalation as a list of tips, the training should show it as a recovery sequence that restores control, clarity, and professionalism.

The current opening-middle-close structure is strong. The next pass should make it more immersive and more cinematic by showing the transition from heat to stability. It should also give the learner stronger language for the opening pivot, the process-clarity middle, and the accountable close.

### Recommended page jobs

| Page type | Direction |
| --- | --- |
| Hero | Frame recovery as regaining command without sounding defensive |
| Core slide 1 | Show the first sentence that lowers heat instead of feeding it |
| Core slide 2 | Show how process visibility reduces frustration |
| Core slide 3 | Show what an owned close sounds like after recovery |
| Practice | Let the learner read the moment where emotional heat can rise or fall |
| Apply | Require the learner to choose the recovery move that stabilizes first and explains second |
| Reflection | Ask for the learner’s personal stabilizing phrase and recovery close |

### Voice direction

This module should sound calm, deliberate, and highly situational. The narration should help the learner understand that recovery is not about sounding softer; it is about sounding more controlled. The strongest supporting lines here are those that make the sequence visible, such as the idea that **people calm down faster when the path becomes legible**.

## Narration design standard

Narration should not merely repeat the on-screen bullets. Instead, each page should include a short note that does one of three jobs: explain what the learner should notice, interpret why a phrase works, or point out what a coach would flag in a real call review.

| Narration mode | Use when |
| --- | --- |
| Interpretation | The slide presents a model or contrast and needs explanation |
| Coaching lens | The slide should teach the learner what to listen for in themselves |
| Transfer prompt | The slide should help the learner carry one behavior into the next real interaction |

## Implementation priority

The implementation pass should first rewrite the hero copy and core slide narratives so each module gains a clearer identity. It should then enrich modeled language, practice framing, coach prompts, and reflection prompts. Finally, it should improve narration notes and any supporting statements so the finished experience feels authored and distinctive instead of evenly templated.
