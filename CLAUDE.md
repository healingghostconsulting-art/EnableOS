- **Language/build:** TypeScript 5.9, **Vite 7** (root = `client/`), bundles server with esbuild for prod.

- **Package manager:** **pnpm** (declared `packageManager: pnpm@10.x`, `pnpm-lock.yaml` present). Use pnpm — npm/yarn will not apply the wouter patch.
- **Tests:** Vitest (`server/*.test.ts`, plus `shared/`, `client/`). Many are **source string-snapshot tests** (assert exact copy exists in `EnableOSViews.tsx`).

```sh

pnpm dev              # start dev server (Express + Vite middleware)
```
- Serves on **http://localhost:3000/** (auto-increments to the next free port up to 3019 if 3000 is busy; override with `PORT`).
- Other scripts: `pnpm build`, `pnpm start` (prod), `pnpm check` (tsc), `pnpm test` (vitest), `pnpm db:push` (drizzle generate+migrate).

### ⚠ Windows / PowerShell gotcha
The `dev` script is written POSIX-style: `NODE_ENV=development tsx watch server/_core/index.ts`. The inline `NODE_ENV=...` prefix does **not** set the variable under PowerShell or cmd, so `process.env.NODE_ENV` may be undefined and the server can fall into the production (static-file) branch. If `pnpm dev` misbehaves on Windows, run with the env var set explicitly, e.g. PowerShell:
```powershell
$env:NODE_ENV="development"; pnpm exec tsx watch server/_core/index.ts
```
(A cross-env shim or a settings tweak would fix this permanently — propose before changing.)

### Refactor risk notes (read before touching layout)
- **Source string-snapshot tests.** `server/enableosTrainingLayout.test.ts` and siblings (`trainingPlayer`, `trainingFlow`, `dashboardLayout`, `pageTransition`, `appNavigation`, `slideChallengeCopy`, …) `readFileSync` the source and assert **exact copy/markup strings** exist. Changing these is global, not training-only.

- **Heavy shared state.** `TrainingExperienceView` holds ~50 `useState` hooks; bands depend on shared state (`trainingWorkspacePage`, `moduleIndex`, `stageIndex`, `lessonPageIndex`, quiz/checkpoint answer maps, narration, celebration prefs). Collapsing/moving a band can silently strand or duplicate state — trace the state a band reads before moving it.
- **Hardcoded sizes / sticky.** e.g. `min-h-[12.6rem]`, curriculum viewer `min-h-[18rem]`/`min-h-[24rem]`, Progress rail `2xl:sticky 2xl:top-6`. Watch these in layout changes.
