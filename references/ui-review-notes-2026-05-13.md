# UI review notes — 2026-05-13

## Initial high-impact surfaces reviewed

### Mission hub landing page

The landing page already has strong visual structure, but the primary CTAs and workspace cards would benefit from more obvious hover, press, and page-transition feedback so the experience feels more responsive and less static.

### Learner workspace

The learner workspace is the most interaction-dense surface and should be the first target for a motion polish pass. The sidebar, assigned re-engagement cards, section cards, and action buttons appear visually consistent, but the overall experience likely still relies on hard state changes instead of smooth transitions when opening training, moving between sections, and interacting with cards or modal-like checkpoints.

## Highest-priority motion candidates

1. Shared buttons and link-buttons across the landing page and learner workspace.
2. Sidebar navigation state changes and card hover/press interactions.
3. Training-launch transitions from learner workspace cards.
4. Modal, checkpoint, and assessment transition states inside the training experience.
5. Section and content reveal transitions for learner workspace cards and supporting panels.
